# Tentang Evriwanken
Website ini berisi pengenalan komunitas dan sekaligus program unggulan yang dimiliki oleh Evriwanken, yakni komunitas di bidang konservasi.

Website ini memiliki tiga bagian utama, yakni navbar, body, dan footer. Seluruh bagian tersebut sudah bersifat responsif, sehingga kompatibel jika diakses melalui perangkat mobile, tablet, hingga desktop.

Pada bagian body, website ini memiliki setidaknya 3 section, yakni hero section, pengenalan Evriwanken, dan program unggulan Evriwanken.
